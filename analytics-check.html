    What to try

    If consent is not chosen, open the Bdesh homepage in a fresh private tab and choose Allow anonymous analytics. If consent is no, analytics is correctly disabled.

    If consent is yes but the SDK has not loaded, an ad blocker or browser tracking protection may be preventing it. In Brave, use the lion Shields menu to allow the analytics request for Bdesh only if you personally want to participate. The site continues working without analytics.

    If the SDK loads but the dashboard still shows no events, visit the homepage after consenting, then check Bdesh's PostHog dashboard. Allow some time for ingestion and refresh the dashboard.

    To opt out, use the Privacy page. Browsing and account functionality do not require analytics.
