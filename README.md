# Bdesh

A student-led, Bangla-first guide to fully funded **undergraduate** study abroad for students following Bangladesh's NCTB curriculum.

## Who it serves

- Class 9–10 students exploring possibilities
- Class 11 students building a foundation
- Class 12 / HSC students preparing applications
- HSC graduates and gap-year students submitting applications

## Planned platform

- Secure student sign-in and private academic profiles
- Personalized roadmaps and application progress tracking
- Searchable, source-verified undergraduate scholarship and university information
- Admission and financial-aid deadlines tracked separately
- Bangla-first content with an English option
- Simple administrator tools for updating guides and opportunity details

## Status

Early development. The previous Shombhabona browser-only prototype is hosted separately on Vercel; it is **not** yet connected to this repository, and its checklist is not a secure cloud-saved account system.

Funding eligibility, scholarship coverage, test requirements, and deadlines must be verified against official sources. Bdesh will not guarantee admission, scholarships, or full funding.

## Privacy

Initial development should not collect passports, household financial documents, or other sensitive information. Accounts for younger users need an age-appropriate consent and privacy design before public release.
