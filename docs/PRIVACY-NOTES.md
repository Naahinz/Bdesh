# Bdesh privacy and launch notes

- The public preview stores only checklist stage, academic group, intended intake and task completion in browser localStorage. Nothing is uploaded.
- A login button must not be exposed until actual authentication, server-side access controls, user data deletion, and consent handling are implemented and tested.
- For Class 9 pupils, review age requirements and guardian consent before creating accounts.
- Do not solicit passports, transcripts, household income, financial documents or exact addresses for the initial public version.
- Scholarship links are starting points only and must never be presented as verified full rides without current official supporting details.
- Vercel project was initially deployed as a separate non-Git prototype. This repository is the canonical source for the next release.
